# dsh-aixterm 工具面板规划（Roadmap）

右侧工具面板采用**图标标签**结构，按功能分类逐步填充。本文件公开，记录每一类的规划、子类、功能清单与实现状态。

## 0. 设计主线

dsh-aixterm 定位：**替代 Xshell / MobaXterm / WindTerm 的 AI 原生终端**。工具规划沿两条线：

1. **专业终端能力**——对齐主流客户端的网络/系统/文件/会话工具
2. **AI 差异化**——把 AI 做成一等公民：人机共享会话、上下文问答、自动诊断、自然语言操作、视觉理解

状态图例：✅ 已实现 · 🚧 开发中 · ⬜ 规划中 · 💡 远期构想

## 1. 右侧工具面板（图标栏，可扩展）

| 图标 | 分类 | 状态 |
|---|---|---|

| 📊 | 资源监控 | ✅ |

| 🌐 | 网络工具 | ⬜ |
| 🛠 | 系统工具 | ⬜ |
| 📋 | 进程管理 | ⬜ |
| 📜 | 日志查看 | ⬜ |

### 1.1 文件（SFTP）— ✅
浏览/上传/下载/新建目录/重命名/删除/改权限/在线编辑/跟随终端目录/传输队列（进度·速度·暂停·继续·取消·重试·断点续传·重名处理·时间戳保留）。

### 1.2 资源监控 — ✅
CPU/内存/负载/开机时长/磁盘/网络速率/登录用户/SSH 会话/SoC 温度/主机名/内核。

### 1.3 网络工具 — ⬜
- ping（连通性/丢包/RTT，持续模式）
- traceroute / tracepath
- TCP 端口连通检测（远端任意主机:端口）
- 本机网络接口详情（IP/掩码/MAC/状态/速率）
- 路由表 / 默认网关
- DNS 解析（正向/反向，指定 DNS 服务器）
- 端口扫描（本机 / 指定网段）
- ARP 表 / 邻居表
> 复用 SSH `exec` 在远端执行；持续流式输出（ping）后续考虑专用通道。

### 1.4 系统工具 — ⬜
- 系统信息（发行版/架构/内核/boot/时区）
- 磁盘分区与挂载（df/分区表）
- 磁盘占用分析（du 排序，最大文件/目录）
- 服务/自启管理（init.d / systemd / procd）
- 软件包管理（opkg/apt/apk 查询与安装）
- 用户/权限（who/当前用户/登录历史）
- 时间/时钟同步状态

### 1.5 进程管理 — ⬜
- 进程列表（PID/用户/CPU%/内存%/命令），按列排序、过滤
- 进程树 / 父子关系
- 查找进程（关键字）
- 终止进程（危险操作走审批）
- 单进程详情（cwd、打开的文件、环境）

### 1.6 日志查看 — ⬜
- 命令历史日志（本插件记录的人/AI 命令，带来源/时间/退出码）
- 终端滚动日志（按会话/时间，浏览/搜索/导出）
- 远端系统日志（dmesg / syslog / 应用日志 tail）
- 日志高亮与过滤（复用关键字高亮）

### 1.7 端口转发 — ⬜
- 全局转发视图（跨会话列出所有 -L/-R/-D）
- 增删查、状态、字节流量统计
- 从会话右键入口提升为独立工具页

### 1.8 连接诊断 — ⬜
- 分阶段诊断：DNS 解析 → TCP 连通 → SSH 握手 → 认证 → 跳板
- 各阶段延迟与失败原因
- 一键诊断报告（供 AI 分析或人工排查）

### 1.9 设备排障 — ✅ 首版

- ✅ 可视化用户方案编辑器：参数、检查顺序、超时与输出上限、分析重点。
- ✅ 版本化 JSON 协议、JSON Schema、示例文件与单个/集合导入导出。
- ✅ 内置模板只读可复制；导入冲突另存，批量校验失败不写入。
- ✅ 用户命令预览确认与 agent 强制审批；日志方案不发送命令。

- 启动异常、服务未启动、存储不足：固定只读检查，保留原始证据与采集时间。
- SSH 先识别远端系统，Linux / BusyBox 执行独立 exec 检查；缺少 systemd 等工具时说明限制。
- 串口 / Telnet 仅读取已有输出，不向交互终端注入命令。
- 用户预览后手动提交到主 AI 会话；agent 共用 `aixterm_diagnose`。
- 输出上限、超时与部分失败明确展示；不自动执行修复。
- 宿主 Windows / Linux / macOS 与远端系统分开处理；CI 增加三平台测试和构建矩阵。

## 7. 优先级建议

| 优先级 | 内容 | 理由 |
|---|---|---|
| P0 近期 | 进程管理、端口转发全局视图、命令片段库、日志查看 | 高频、低成本、复用 SSH exec |
| P1 中期 | 连接诊断、审计日志、AI 自动诊断、批量执行 UI | 高价值，直接解决排障痛点 |
| P2 远期 | 会话回放、协作、定时任务、只读会话 | 成本高或需求低频 |

## 8. 实现约定

- 工具面板复用 SSH `exec`；危险操作沿用 `dangerPatterns` 审批
- 占位面板先展示规划清单，随实现替换为真实 UI
- 每完成一个能力，更新本文件对应复选框
- AI 类工具优先设计为“人机共享、可被 agent 调用”（与主会话一致）
