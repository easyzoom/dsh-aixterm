# dsh-aixterm 工具面板规划（Roadmap）

右侧工具面板采用**图标标签**结构，按功能分类，逐步填充。本文件公开，记录每一类的规划与实现状态。

## 分类总览

| 图标 | 分类 | 状态 |
|---|---|---|
| 📁 | 文件（SFTP） | ✅ 已实现 |
| 📊 | 资源监控 | ✅ 已实现 |
| 🌐 | 网络工具 | ⬜ 规划中 |
| 🛠 | 系统工具 | ⬜ 规划中 |

> 分类可扩展；新工具类随时追加到图标栏，内容以占位面板起步。

## 1. 文件（SFTP）— ✅

- 浏览/进入/上级目录
- 拖拽上传、点击下载
- 新建目录、重命名、删除、改权限
- 双击在线编辑文本
- 跟随终端当前目录（OSC 7）
- 传输队列：进度、速度、暂停/继续/取消/重试、断点续传、重复目标处理、时间戳保留

## 2. 资源监控 — ✅

- CPU、内存使用率
- 负载（1/5/15）、开机时长
- 磁盘根分区用量
- 网络收发速率
- 登录用户数、SSH 会话数
- SoC 温度（可用时）
- 主机名、内核版本

## 3. 网络工具 — ⬜ 规划

- ping（连通性、丢包、RTT）
- traceroute / tracepath
- 端口连通检测（TCP connect）
- 本机网络接口详情（IP/掩码/MAC/状态）
- 路由表
- DNS 解析（正向/反向）
- 开放端口扫描（本机）
- 目标端口扫描（远端）

> 多数能力可复用 SSH `exec` 在远端执行；涉及频繁/流式输出的（ping 持续）后续考虑专用通道。

## 4. 系统工具 — ⬜ 规划

- 进程列表 / 按 CPU、内存排序
- 终止进程（危险操作走审批）
- 服务/自启管理（init.d / systemd / opkg）
- 软件包管理（opkg/apt）查询与安装
- 系统日志查看（dmesg / syslog）
- 磁盘分区与挂载信息
- 系统信息（发行版、架构、boot）

## 5. 未来候选分类

- 终端历史与回放
- 端口转发管理（现状在会话右键里，可提升为工具页）
- 宏管理（现状在标签栏）
- 连接诊断（连通性 + 认证 + 跳板）

## 实现约定

- 工具面板通过 SSH `exec` 复用现有会话，危险操作沿用 `dangerPatterns` 审批
- 占位面板先展示规划清单，随实现替换为真实 UI
- 每完成一个能力，更新本文件对应复选框
